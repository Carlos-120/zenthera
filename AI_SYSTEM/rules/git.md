# Reglas de Git

- No trabajar directamente en main.
- Una rama por tarea.
- No mezclar funcionalidades.
- Revisar git status antes de comenzar.
- Revisar git diff antes de entregar.
- No usar git reset --hard.
- No usar git clean -fd.
- No forzar push.
- No realizar merge sin aprobación humana.
- El agente puede preparar un commit, pero Carlos decide integrarlo.
