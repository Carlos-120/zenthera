# Zenthera AI Agents Index

Este archivo registra los agentes disponibles del sistema.

## Atlas

- Rol: Coordinador
- Archivo: `AI_SYSTEM/agents/coordinator.md`
- Función: analiza el estado del proyecto, organiza tareas y decide el siguiente paso.
- No programa.

## Builder

- Rol: Desarrollador
- Archivo: `AI_SYSTEM/agents/developer.md`
- Función: implementa únicamente la tarea activa.
- No aprueba su propio trabajo.

## Inspector

- Rol: Revisor independiente
- Archivo: `AI_SYSTEM/agents/reviewer.md`
- Función: revisa código, pruebas, seguridad y cumplimiento.
- No corrige código durante la revisión.

## Scribe

- Rol: Documentador
- Archivo: `AI_SYSTEM/agents/documenter.md`
- Función: actualiza documentación y estado del proyecto.
- No modifica código de producción.
